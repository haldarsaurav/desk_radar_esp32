# Permission and reuse

**All rights reserved. Ask first, and receive written permission before reuse.**

The owner wants the project to be viewable as a showcase, without granting others permission
to copy its work or use it as a reference for an AI-generated replacement. Both repositories
carry the same [full proprietary licence](../LICENSE) and [AI-use policy](../AI_POLICY.md).

## Examples

| Proposed action | Owner's permission policy |
| --- | --- |
| Read the public feature guide on GitHub | Viewing through the service is covered by the applicable platform terms |
| Flash the firmware onto your own ESP32 | Ask for written permission first |
| Copy screen artwork or documentation into another project | Ask first |
| Sell a device incorporating the project | Ask first; disclose commercial use |
| Give an AI the files or screenshots to recreate the implementation or presentation | Ask first, including when the output uses different source text |
| Train a model, create embeddings for reuse, or build a dataset from the project | Ask first |
| Star the project, cite its URL or request permission | None of these actions grants reuse permission |

Requests should identify the requester, material/version, intended use, commercial status,
AI involvement and planned distribution. Send the request through the
[public repository's issues](https://github.com/haldarsaurav/desk_radar_esp32/issues)
or a contact method published on [the owner's profile](https://github.com/haldarsaurav).
Silence is not consent. Only the owner can grant project permission.

## What a notice can and cannot do

A restrictive notice expresses the owner's terms; it does not physically prevent downloads
or guarantee that third parties obey. GitHub's public-repository terms include service-specific
viewing and forking rights. See [GitHub's licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).

Copyright does not create ownership of abstract ideas, methods or algorithms simply because
they are described in a project. The licence therefore distinguishes protected project material
from generic features and independently created work. See the
[U.S. Copyright Office's software guidance](https://www.copyright.gov/register/tx-programs.html).
Legal protection and exceptions depend on applicable law; the notice preserves those limits.

Text/data-mining reservations can have jurisdiction-specific requirements. For example,
[German Copyright Act section 44b](https://www.gesetze-im-internet.de/urhg/__44b.html) specifies
machine-readable reservation for online works. These repository notices do not claim that a
particular crawler must recognize them or that every technical/formal requirement is satisfied.
Third-party libraries, data and trademarks keep their own terms.
